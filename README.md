Entry for the [make.fun bounty "Warning Label for Humans: One Line, Big Laugh"](https://make.fun/bounty/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85): the funniest single-line safety warning label that should come printed on every human being, at most 160 characters.

## The line

> WARNING: This human will apologise to the furniture after walking into it, then glare at the furniture for being there.

The comedy is a double beat inside one idea: first the human treats the furniture as a person owed an apology (recognition — everyone has apologised to an object they bumped into), then the blame reverses and the furniture is at fault for existing. The turn lands in the last few words, in the exact register of a printed safety notice.

## Run it

```sh
node main.ts
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), exactly 119 characters, no trailing newline.
